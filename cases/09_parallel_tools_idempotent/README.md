# 案例 09 · 并行工具调用与幂等（🟡 中级）

> 一句话：**一批独立工具调用并行执行提速，但相同调用只执行一次，结果一一配对。**

## 难点是什么
模型一次回复常带多个**互相独立**的工具调用。串行执行慢；而“同工具同参数”的重复调用
如果并发重放，会造成**重复副作用**（重复下单、重复记账）。

## 为什么会发生
把每个 tool_call 都无脑执行一遍，既不并行（慢），也不去重（副作用重复）。
结果既慢又不安全。

## 生产级解法（看代码 `main.py`）
1. **幂等去重**：按 `(工具名, 参数签名)` 分组，同一签名只保留一个代表调用执行。
2. **并发执行**：去重后的调用用线程池并发跑，显著缩短耗时。
3. **结果映射**：按 `tool_call_id` 把结果一一映射回原调用，保证模型正确配对。
4. 每个工具带计数器，测试可验证“相同调用只执行一次”。

## 调试清单
- [ ] 去重键是“工具名 + 参数签名”吗？只按工具名去重会误杀不同参数。
- [ ] 并发会不会加剧副作用？不同调用之间要真正独立才能并行。
- [ ] 结果按 tool_call_id 配回了吗？配错模型会拿错结果。
- [ ] 有执行计数/审计吗？方便验证幂等。
